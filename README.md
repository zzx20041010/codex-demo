# Codex 入门练习：JCAT 单笔订单计算器

这是一个零基础可运行的 Python 小项目。你可以先运行它，再让 Codex 帮你改动一处功能、运行测试并解释改动。**金额只是输入示例，不代表 JCAT 的真实成本或利润。**

## 启动

需要 Python 3.9 或更新版本；只使用 Python 标准库，无需安装依赖。

1. 在 GitHub 页面点击 **Code → Download ZIP**，解压并在终端进入 `codex-demo` 文件夹；也可以运行 `git clone https://github.com/zzx20041010/codex-demo.git`，再运行 `cd codex-demo`。
2. 检查 Python：`python --version`（有些电脑需使用 `python3`，Windows 也可试 `py`）。
3. 启动：`python app.py`。按提示输入售价、产品成本、运费、平台费率和售后损耗率，每项输入数字后按回车。费率输入百分数，例如 `5` 表示 5%；两个费率直接回车均默认为 0。若上一步使用的是 `python3` 或 `py`，这里及以下命令也换成相同名称。

## 计算公式与示例

```text
平台费 = 售价 × 平台费率
预估售后损耗 = 售价 × 售后损耗率
简化利润 = 售价 − 产品成本 − 运费 − 平台费 − 预估售后损耗
```

本练习约定两项费率均以售价为基数。**售后损耗率是平均摊到每单、占售价的预估损耗比例，不是退货订单占比。** 实际退货涉及退款、货品回收、往返运费及平台费返还，不能用本公式完整描述。

| 输入或结果 | 示例值 |
| --- | --- |
| 售价 | 59.90 元 |
| 产品成本 | 22.40 元 |
| 运费 | 3.50 元 |
| 平台费率 | 5%（虚构教学值） |
| 售后损耗率 | 3%（虚构教学值） |
| 平台费 | 2.995 元 |
| 预估售后损耗 | 1.797 元 |
| 简化利润 | 29.21 元（未舍入结果为 29.208） |

命令行依次输入 `59.9`、`22.4`、`3.5`、`5`、`3`，显示 `简化利润：29.21 元`。两个费率直接回车，仍显示原来的 `34.00 元`。

Python 函数接收小数费率（与命令行的百分数输入不同）：

```python
from app import calculate_profit

calculate_profit(59.9, 22.4, 3.5)              # 34.0，兼容原来的三参数调用
calculate_profit(59.9, 22.4, 3.5, 0.05, 0.03)  # 29.21
```

### 边界情况

- 金额允许 0，负数会抛出 `ValueError`；负利润允许返回，表示模型中的亏损。
- 每项费率允许 0% 到 100%（含两端），越界会抛出 `ValueError`。两项费率之和可以超过 100%，程序照常返回负利润，不擅自截成 0。
- 所有金额和费率必须是有限数字，拒绝 `NaN`、正负无穷。命令行输入非数字会显示错误提示。
- 售价为 0 时，两项按售价计提的费用均为 0；已有产品成本和运费仍扣除。
- 使用 Python `float` 和 `round(..., 2)`，仅在最后保留两位小数。浮点数及 Python 的舍入规则可能影响极端小数结果，这不是财务结算系统。

广告费、税费及完整退货流程仍未纳入，示例费率未经任何平台核实，不能用于实际经营决策。

### 为什么适合零基础学习

两个参数都只增加一次“售价 × 比例”的计算，便于手算核对；默认值演示如何扩展函数并兼容旧调用。你也能练习百分数转换、输入校验、正常与异常测试，以及同步维护文档，无需安装新依赖。
