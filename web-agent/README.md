# 罗盘选品工作台

本机网页界面，用于辅助执行“抖音电商罗盘商品卡榜单 → 商品链接 → 1688 以图搜款与规格核价”流程。

## 运行

前置条件：Windows、Node.js 20+、已安装并可启动 Ego Lite / ego-browser。

在 PowerShell 中运行：

~~~powershell
cd D:\Codex\work\douyin-1688-web-agent
npm start
~~~

然后打开 http://127.0.0.1:8787。

## 当前功能

- 在 Ego 浏览器中打开电商罗盘商品卡榜单。
- 从当前榜单页读取真实商品链接，按目标数量去重并保存在本机。
- 打开 1688 以图搜款页面。
- 手动补充货源链接、供应商、规格、采购单价、起批量、运费和匹配状态。
- 导出 UTF-8 CSV。

## 边界

页面筛选、随机类目切换、商品图上传、规格匹配和价格条件核验仍需在已登录的 Ego 浏览器里确认。工作台不会把 1688 搜索卡片最低价当成同款成本，不会下单、加购物车或联系供应商。

网页服务只监听 127.0.0.1。浏览器页面、商品记录和导出文件保存在本机 data/ 目录，不会上传到云端。不要把 data/state.json 提交到仓库。

网页界面不调用外部大模型 API，所以不需要配置 API Key；目前它是本地浏览器工作台，不是无人值守的全自动采集服务。
